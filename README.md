# CloudFPGA

CloudFPGA는 자연어로 Verilog 설계와 테스트벤치를 생성하고, Icarus Verilog로 시뮬레이션해 파형을 확인하는 FPGA 학습 프로젝트입니다.

현재 **Step 1 Phase 1 백엔드** 구현과 로컬 검증을 마쳤습니다. Verilog 생성·자동 수정·시뮬레이션 API를 구현했고, 실제 AND 게이트의 VCD 생성과 백엔드 테스트 13개를 확인했습니다.
